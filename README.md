# 🍱 مشروع تحليل الأداء والتنبؤ بالطلب لشركة توصيل وجبات جاهزة (Food Demand Analysis)

مستودع برمجي متكامل لتحليل سلاسل الإمداد، واختبار الأثر الإحصائي للحملات الترويجية والخصومات، والتنبؤ بالطلب الأسبوعي لشبكة من 77 مركز تجهيز عبر 145 أسبوعاً من البيانات التاريخية.

---

## 1. المشكلة وسياق العمل (The Business Problem)
تعاني الشركة من معضلة مزدوجة تكبدها خسائر بالملايين:
* **تلف وهدر مواد خام سريعة الفساد** في بعض مراكز التجهيز بسبب الإفراط في الشراء.
* **نفاد متكرر للوجبات والاعتذار للعملاء (Stockouts)** في مراكز أخرى نتيجة نقص المواد.
* **السبب الجذري:** اعتماد مديري المراكز على التقديرات الشخصية والتخمين، مع غموض الأثر الحقيقي لحملات البريد الترويجي والظهور في الصفحة الرئيسية والخصومات السعرية.

---

## 2. أهم 3 نتائج رئيسية من البيانات (Top 3 Findings)

1. **المضاعفة القياسية لمبيعات العروض المشتركة (+286.1% Lift):**  
   أثبت اختبار **Mann-Whitney U** بدلالة إحصائية قاطعة ($p < 0.001$) أن تزامن البريد الترويجي مع إبراز الوجبة في الصفحة الرئيسية يرفع متوسط الطلب الأسبوعي بمقدار **3.8 أضعاف** مقارنة بالأسابيع الاعتيادية (من 215 إلى 830 طلباً).
2. **تركيز الطلب وفق قاعدة باريتو (Pareto Concentration):**  
   **4 فئات فقط** (المشروبات، أطباق الأرز، السندويشات، والوجبات السريعة) تستحوذ على **75.22%** من إجمالي حجم الطلب البالغ 119.5 مليون طلب، و **21 وجبة فقط** من أصل 51 وجبة تمثل 80% من النشاط التشغيلي اليومي.
3. **تذبذب حاد يهدد المأكولات البحرية والسندويشات ($CV > 1.4$):**  
   بينما تحافظ المشروبات على نمط طلب مستقر للغاية ($CV = 0.58$)، تبلغ ذروة التذبذب وعدم اليقين في وجبات السندويش (وجبة 1971 بـ $CV = 1.45$) والمأكولات البحرية (وجبات 2444 و 1445 بـ $CV > 1.3$)، وهي المتسببة في معظم الهدر وتتطلب مخزون أمان إضافياً لا يقل عن 35%.

## 3. كيف استخدمت الذكاء الاصطناعي في المشروع؟ (AI & Copilot Customization)
1. **حوكمة مساعد الذكاء الاصطناعي (`AGENTS.md` و `.github/copilot-instructions.md`):**  
   وضع قواعد عمل صارمة تمنع المساس بالبيانات الخام في `data/raw/`، وتلزم بالتحقق من تطابق عدد الصفوف ومجموع الطلبات بعد كل دمج، وتمنع استخدام لغة السببية غير المثبتة، وتحظر أي أرقام بلا مصدر برمجي مباشر.
2. **تطوير مهارات برمجية مخصصة (`.github/skills/`):**  
   * `promotion-impact-evaluator`: مهارة إحصائية متقدمة لحساب المقارنات الزوجية اللابارامترية (Mann-Whitney U) ونسب الارتفاع وعزل التداخل.
   * `demand-volatility-kpis`: مهارة سلاسل الإمداد لحساب معامل الاختلاف $CV = \sigma / \mu$ وتصنيف باريتو 80/20.
3. **نموذج التعلم الآلي للتنبؤ الأسبوعي (Random Forest Forecaster):**  
   تدريب نموذج انحدار شجري متقدم على التنبؤ بطلبات آخر 10 أسابيع وتقدير مبيعات الأسبوع القادم في `reports/test_predictions.csv`، محققاً خطأ مطلقاً **MAE = 88.00** بتفوق بلغ **6.69%** على خط الأساس التاريخي.

## 4. لمستنا الخاصة (Our Unique Value-Add)
* **تحليل حساسية عتبة الخصم (Discount Threshold Analysis):** كشفنا أن الخصومات دون 10% لا تحدث أي فارق يذكر في الطلب، بينما تبدأ نقطة الانطلاق الحقيقية عند **15% خصم فأكثر** مقترنة بالترويج في الواجهة.
* **مصفوفة المخزون الاحتياطي الذكي (Safety Stock Risk Matrix):** تصنيف تفاعلي يدمج حجم الطلب مع معامل التذبذب في ملف [docs/meal_volatility_rankings.csv](file:///c:/Users/weam/Desktop/WAC/AI%20DS/Final%20Project-20261025T163949Z-1-001/food-demand-analysis/docs/meal_volatility_rankings.csv) لتوجيه المشتريات بدقة رقمية.

## 6. طريقة التشغيل وإعادة الإنتاج (How to Run)

### المتطلبات الأساسية
* بيئة بايثون (Python 3.10+)
* تثبيت الحزم المطلوبة:
```bash
pip install pandas numpy scipy scikit-learn matplotlib seaborn
```

### خطوات التشغيل
1. استنساخ المستودع:
```bash
git clone https://github.com/weam/food-demand-analysis.git
cd food-demand-analysis
```
2. تشغيل فحص البيانات والتحليل الكامل وتوليد الرسوم:
```bash
python scripts/run_full_analysis.py
```
3. تشغيل دفتر التحليل وحفظ نتائجه:
```bash
python scripts/execute_notebook.py
```
أو فتح الدفتر عبر بيئة Jupyter Notebook أو VS Code:
```bash
jupyter notebook notebooks/analysis.ipynb
```
