## 3. هندسة المتغيرات المشتقة (Feature Engineering)
بناءً على القرارات السابقة، تم استحداث المتغيرات التحليلية التالية:
* **الإيرادات الأسبوعية:** `revenue = checkout_price * num_orders`
* **مبلغ الخصم الترويجي:** `discount_amount = np.maximum(0, base_price - checkout_price)`
* **نسبة الخصم الترويجي:** `discount_rate = np.maximum(0, (base_price - checkout_price) / base_price)`
* **مؤشر وجود خصم:** `has_discount = (base_price > checkout_price).astype(int)`
* **مؤشر وجود أي عرض تسويقي:** `has_promotion = ((emailer_for_promotion == 1) | (homepage_featured == 1)).astype(int)`
